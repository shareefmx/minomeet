🚨 Chapter 1: The Problem Statement

In today's hybrid work environment, professionals spend an average of 21.5 hours per week across Google Meet, Zoom, Microsoft Teams, and Slack Huddles. Despite this massive investment of time, post-meeting execution remains severely fractured due to four critical bottlenecks:

1. Note-Taking Fatigue & Divided Focus

Participants are constantly distracted trying to jot down conversation fragments instead of actively contributing to strategic discussions. Key verbal subtleties and context are lost.

2. "Meeting Amnesia" & Lost Deliverables

Decisions made verbally during a 45-minute sprint planning call often vanish. Action items lack explicit ownership and due dates, leading to redundant follow-up calls.

3. Time Waste on Manual MOM Summaries

Drafting executive summaries and emailing team recaps takes 30 to 60 minutes of tedious administrative effort after every single meeting.

4. Invasive Cloud Bots & Privacy Leaks

Traditional AI note-takers require third-party bots to join calls as uninvited attendees, storing confidential intellectual property on opaque external cloud servers.

The Core Objective of Minomeet AI: Provide an autonomous, 100% private, on-device and cloud-flexible meeting intelligence platform that captures conversations directly from hardware with zero invasive bots, synthesizing raw speech into executive-ready deliverables in under 5 seconds.

🏗️ Chapter 2: Core Solution & System Architecture

Minomeet AI employs a 4-Stage End-to-End Intelligence Pipeline that isolates audio ingestion, live transcription, neural synthesis, and structured storage directly on the local machine:

SYSTEM ARCHITECTURE TOPOLOGY 100% ON-DEVICE & DIRECT FRONTIER AI
[ AUDIO INGESTION ] ──► [ REAL-TIME STT ] ──► [ NEURAL SYNTHESIS ] ──► [ STRUCTURED OUTPUT ] • Microphone • Web Speech API • Google Gemini • Executive Summary • System Audio • Neural Whisper • OpenAI GPT-4o • Key Decisions (3) • Video Conference • Speaker Diarize • Claude 3.7 Sonnet • Action Items Matrix • Audio Files (.mp3) • Millisecond Stamps • Groq LPU / Ollama • 1-Click Email Recap

Key Architectural Principles

Layer Engine / Tech Stack Value Proposition
Dual Audio Capture WebRTC AudioContext + System Loopback Captures user mic and remote attendees simultaneously with real-time waveform equalization.
Speech-to-Text (STT) Browser Neural STT + Whisper Transformer Converts live voice to text with speaker labeling and continuous time-aligned transcripts.
Dynamic AI Resolver Multi-Provider Client/Server Orchestrator Single source of truth routing prompts to Google, OpenAI, Claude, Groq, or local Ollama.
Local Data Store LowDB Atomic JSON Archive 100% private local database stored at server/data/db.json. Zero external telemetry.
🔒 Privacy Guarantee: Minomeet never transmits raw audio files to central servers. When cloud AI synthesis is enabled, only anonymized textual transcripts are sent directly to your chosen provider via your private API key.

How to Configure Your API Key (3 Simple Steps)

  1. Open Settings from the left sidebar and click on the AI Model tab.
  2. Select your preferred AI provider (e.g., Google Gemini) and paste your secret API key.
  3. Click "Test Connection" to verify real-time connectivity, then click "Save Global Configuration".

🚀 Chapter 6: Installation & Operations Manual

Prerequisites

  • Node.js: v18.0.0 or higher (v20+ LTS strongly recommended)
  • npm / pnpm / yarn package manager
  • Python 3.10+ (Optional: for local neural speech transcription)
  • Browser: Chrome, Edge, Brave, or Safari with microphone permissions enabled

Step-by-Step Installation Commands

# 1. Clone the repository from GitHub
git clone https://github.com/shareefmx/minomeet.git
cd minomeet

# 2. Install root, client, and server dependencies
npm install

# 3. (Optional) Install Python packages for on-device neural transcription
pip install -r requirements.txt

# 4. Start the development server
npm run dev

• Client Web App: http://localhost:5173
• Server Backend API: http://localhost:5001

🔒 Chapter 7: Privacy, Security Governance & Troubleshooting

🛡️ 100% Local Data Governance

Minomeet AI is engineered from the ground up for strict confidentiality:
• Zero External Telemetry: No Google Analytics, Mixpanel, or third-party trackers.
• Local JSON Archive: All meeting transcripts and summaries reside on your local machine at server/data/db.json.
• Direct API Routing: When using cloud AI, requests flow directly from your machine to the LLM API without intermediary proxy servers.

Frequently Asked Questions & Troubleshooting

Question / Issue Solution & Best Practice
Microphone not capturing system audio When recording video conferences, choose "Mixed (Mic + System)" and select the Chrome Tab or Entire Screen with "Share System Audio" checked.
"AI Model Not Configured" alert Click the "Configure AI Model & API Key" banner on the Home page and enter your Google Gemini, OpenAI, Claude, or Groq API key in Settings.
Can I use Minomeet 100% offline? Yes! Install Ollama locally (e.g. ollama run llama3.3) and select Ollama in Settings. Zero bytes leave your machine.
